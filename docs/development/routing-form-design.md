# 路由模板表单设计

模板库统一创建、编辑、复制、删除和绑定整份模板。编辑器只有负载均衡、路由组、故障转移、JSON 四个页签；无模板默认策略、自动路由、预算路由、健康检查或右侧摘要预览。

## 负载均衡

选择公开模型添加一条规则，然后选择策略。切换到 traffic-split 创建当前模板的独立部署权重，初值均为 1。权重来源可切为继承默认，省略 allocations 并实时读取模型管理默认配置；切回自定义重新建立独立权重。切换其他策略删除 allocations。没有规则的模型继承模型默认。

每行显示提供商/凭据名称、完整上游型号、公开模型、协议及辅助部署 ID，输入相对权重。0 排除部署；空输入视为无效，不能自动写成 0。已删除部署引用可见，后端拒绝失效权重。部署地址和凭据仍在模型管理维护。

## 路由组弹窗

填写组名、多选成员和组策略。成员搜索和已选数量可见；当前模板每个公开模型最多占用一组。加权策略使用独立部署权重，与模型默认权重无关。弹窗保存只更新模板草稿，提交模板后生效。列表可展开调用说明；仍被回退引用的组禁止删除并说明原因。

## 故障转移弹窗

选择主模型或组、错误类别、按顺序添加备用目标；支持排序、移除和清空。三种类别分别保存。清空后保留源到空数组表示禁用；删除整条映射恢复继承。弹窗和模板提交均校验重复、自引用、循环及目录引用。

## JSON 与完整指南

表单转换生成完整 JSON；合法 JSON 可同步回三个业务分区，后续修改表单必须覆盖旧 JSON 草稿。非法 JSON 阻止保存和切回表单。完整指南大弹窗包括字段、策略、可复制完整示例、绑定与执行顺序、LiteLLM 对照和校验错误；移动端内容滚动，页签可换行。

详细契约和后端边界见 routing.md。所有表单、转换和接口改动都有单元、后台回归与浏览器数据面验证；测试数据在结束时清理。
