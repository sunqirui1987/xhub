# 模板内路由组与故障转移

路由组归属于模板 routing_groups 数组，随模板一起保存、复制、绑定和删除。模板页面不调用历史 /routing/groups 接口单独写组。不同模板的成员占用与权重彼此独立。

组对象包含 group_name、非空 models、routing_strategy，以及加权策略可选的 routing_strategy_args.allocations。组名 1–64 字符，不含空白或星号，default 保留，不可与公开模型重名。成员必须为确切公开模型，禁止组套组；每模型在同一模板最多属于一组。

API model 填组名时展开所有成员部署并应用组策略；填成员名时仅路由到该成员的部署，精确 model_routes 规则优先。组权重使用真实部署 ID；未列出的部署默认 1，0 排除，非空配置至少一个正权重。成员改变时表单移除旧权重，并为新增部署初始化 1。

模板三类回退表可使用模型或组作为源及目标，目标顺序保留。组失败后的回退队列为请求私有，不修改共享配置；切换目标后重新解析目标策略。显式组源回退优先于成员源策略，权限、能力与预算仍按实际成员检查。所有默认与模板链在同一图上判环。正在被任一回退引用的组不可从表单删除。

新模板显式 routing_groups: [] 不继承历史全局组。旧文档缺少该字段时兼容历史存储，但新界面统一在模板中管理。完整字段、合并规则和架构见 routing.md；交互规范见 routing-form-design.md。
