# 模型广场与本地模型列表

价格页保留两个入口：模型广场、本地模型列表。模型供应商标签已移除。模型广场使用 Modelink 的市场资料和侧栏筛选结构，本地列表负责管理持久化档案。

## 数据与状态

默认价格源为 `https://api.modelink.ai/v1/market/models`。手动与定时同步使用同一个后台流程，`XHUB_PRICE_FEED_URL` 可指定内部镜像。完整定价档位、变体、模态、能力、供应商和文档字段保留在本地快照；手工价格覆盖与上下架状态独立存储。服务启动优先恢复快照，因此离线重启可继续查看已保存资料。

| 数据 | 持久化位置 | 用途 |
| --- | --- | --- |
| 完整市场快照 | `price_snapshot/catalog` | 市场基线及历史记录 |
| 人工价格 | `price_model/<模型 ID>` | 网关生效价格覆盖 |
| 上下架状态 | `price_listing/<模型 ID>` | 控制广场展示 |

广场只展示市场记录中公开、尚未退役、未下架且未被上游撤回的模型。本地自定义资料和历史记录保留在本地列表。上游不再返回的模型标记为 `feed_unavailable`，保留资料但退出广场；模型重新出现后使用新资料。刷新失败保留当前快照。

下架只隐藏广场展示，保留价格及已配置的调用接口。已有部署的禁用和访问权限由部署管理负责。旧版价格删除接口兼容转为下架，旧删除标记迁移为下架。自定义模型没有市场基线时，恢复价格返回 409，避免清除其唯一记录。

## 页面流程

1. 广场提供搜索、排序、输入输出模态、上下文、能力、供应商和特性筛选。特性同时包含市场 `features` 和运营 `hot_tags`。计数来自实际合格数据；不会把广场供应商数强行固定为 20。供应商配置选择器使用“共 N 个供应商，当前匹配 M 个”。
2. 本地列表展示全部档案，可搜索与按下架状态筛选。支持详情、下架和重新上架，不提供删除。非公开、退役、撤回和自定义模型不能通过页面强制进入广场。
3. 手动同步成功后，读取当前用户可见部署，提示尚未配置的在售公开模型。点击“添加此模型”进入编辑器并预选价格模型；确认配置后才创建部署。
4. 上游模型联想列表使用获取到的完整模型集合，支持滚动、搜索、键盘选择和手工 ID，不截断结果。
5. 点击模型打开内部详情，包含模型价格、接入信息、API 接入、调用文档。完整价格保留全部币种、档位与变体，缺失价格显示未提供。卡片优先展示输入输出费用，其余价格在详情查看。

## 接口与内部文档

- `GET /price/catalog`：管理员读取本地目录，包含来源、时间、完整模型字段及 `delisted`。
- `POST /price/model/listing`：正文 `{"id":"模型 ID","delisted":true}`，设置下架；false 表示取消下架。缺失字段或非法类型 400，未知 ID 404，无管理会话 401。
- 旧 `DELETE /price/model`：保留兼容性，执行下架。
- `POST /reload/model_cost_map`：同步并保存本地快照。
- `/schedule/model_cost_map_reload`：配置或取消定期同步，状态使用对应 `/status` 入口。

内部接入信息来自实际部署及已登记端点，分页读取部署以避免遗漏。示例使用对外模型名称和 `XHUB_API_KEY` 环境变量，不读取或展示供应商密钥。未部署、禁用或未知专用协议不会产生推测的调用示例。媒体专用格式使用端点资料说明；外链只接受 HTTP/HTTPS。
