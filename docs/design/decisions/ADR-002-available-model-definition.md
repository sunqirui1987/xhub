# ADR-002 当前账号可用模型的定义

> **目标设计，不是当前行为。** 见 [docs/current/](../../current/)。

状态：Proposed（待实施）。日期：2026-10-02。

## Context / 背景

/mine-models 是普通用户的模型选择入口。静态价格目录、管理员配置和供应商凭据条目不能证明该用户可以调用。当前 /model/available 已做部分权限过滤，但缺少适配器、部署、配置、凭据与健康的完整判断。

必须保证每个返回的操作在列表快照时至少有一个合法部署；列表不能授予新权限，也不能承诺未来外部服务一定成功。

## Decision / 决策

AvailabilityService 对 principal/scope/model/operation 计算授权、发布状态、有效部署、适配器能力、必要配置/凭据、路由健康及价格可确认性。逐部署验证后按 alias 聚合 operations，不能先去重再检查第一条部署。

模型广场展示已发布目录；我的模型与调试台只使用当前账号 available。价格资料用于规格和报价来源，不直接生成可选模型。缓存包含权限、目录、部署与操作版本，并处理凭据撤销和健康变化。

401、403、503 与成功空列表分别表示身份失效、权限拒绝、依赖不可确认和确实无可用项。关键读取错误拒绝快照并提供去敏 request_id；确定无效的单个部署可以排除，另有有效部署时仍保留该别名。

返回数据不暴露内部部署地址、凭据引用和上游错误原文。列表不预占预算，推理启动重新确认授权、部署和余额。

## Consequences / 影响

前端可以沿用模型广场的卡片与筛选，但需要明确空态、权限态和失败态。服务端引入批量快照读取，避免每张卡片多次查询。实际开放能力可能少于价格目录，这是部署和验证状态的准确反映。

充分性来自见证部署：任何返回的 operation 都是至少一条部署通过所有条件后的聚合结果。下界是状态变化与外部不可预测性；一次读取无法保证稍后的凭据、预算、健康不变，因此调用入口重检不可省略。

## Rejected alternatives / 否决方案

- 用管理员 /model/info 替代 available：会混入未授权或未部署条目。
- 依赖前端过滤：admin 数据与内部字段已先泄漏。
- 依赖静态价格 capability：计费资料不证明协议已实现。
- 加载错误统一返回空数组：掩盖权限与配置故障。
